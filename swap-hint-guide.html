Swap Hint Guide

Learn when Swap Hint is worth using, how Swap Cost fits into your run, and why timing matters more than simply using more hints.

What Swap Hint does
Swap Hint is a recovery tool. It helps you break a stall without solving the puzzle for you.

Best time to use it

  • Late in the puzzle when one good move can unlock the rest of the board.
  • During a daily run when finishing matters more than squeezing out every last point.
  • When you are looping through the same unhelpful moves and need to reset momentum.
The strongest Swap Hint use is usually one decisive use at the right moment, not several early uses that burn value too soon.

When to hold it

Avoid using Swap Hint too early when the board still has lots of natural moves available.

If you are chasing a better score, treat Swap Cost like a limited resource and wait until the board actually stalls.

Simple strategy
Use visual structure first, then spend points only when the trade actually helps.

Before using Swap Hint

  • Check corners, strong edges, and obvious visual lines.
  • Look for one misplaced cluster instead of scanning the whole board.
  • Give yourself one more clean read before spending points.

After using Swap Hint

  • Take advantage of the board momentum immediately.
  • Do not fall back into random swapping.
  • Try to finish the run without spending again unless the board stalls hard.
